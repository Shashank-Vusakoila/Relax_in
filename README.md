# RelaxIn — Ultra Luxury Spa & Wellness Website

A production-ready Next.js 14 luxury spa website with immersive animations, 3D effects, and complete booking system.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📁 Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage with hero, services, experience, membership, gallery, testimonials |
| `/services` | All treatments with details & pricing |
| `/booking` | 5-step booking wizard |
| `/gallery` | Filterable photo gallery with lightbox |
| `/membership` | Membership tiers |
| `/shop` | Spa product store |
| `/about` | Brand story & team |
| `/contact` | Contact form & info |
| `/admin` | Admin dashboard (login: any credentials) |

## ✨ Features

- **Ultra-luxury light theme** with gold accents
- **Custom animated cursor** 
- **Loading screen** with brand animation
- **Parallax scrolling** effects
- **3D card effects** in Experience section
- **Particle animations** in Hero
- **5-step booking wizard** with confirmation
- **Admin dashboard** with booking management
- **Animated testimonials** carousel
- **Gallery with lightbox** and category filter
- **Responsive** across all devices
- **Framer Motion** animations throughout

## 🎨 Design System

**Fonts:** Cormorant Garamond (headings), Jost (body), Pinyon Script (accents)

**Colors:**
- Gold: `#C9A96E`
- Cream: `#FAF8F4`
- Charcoal: `#2C2520`
- Stone: `#B8A898`

## 🔧 Environment Setup

Copy `.env.example` to `.env.local` and fill in values.

## 🚀 Vercel Deployment

1. Push to GitHub
2. Import to Vercel
3. Set environment variables
4. Deploy!

## Admin Access

Visit `/admin` — use any username/password for demo access.
